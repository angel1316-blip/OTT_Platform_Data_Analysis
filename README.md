**Project Overview**

A simple OTT Platform Data Analysis project developed using Python and Pandas.

**Objectives**
1. Load Netflix OTT dataset.
2. Check and clean missing values.
3. Count Movies vs. TV Shows.
4. Find the most popular genres and top release years.
5. Identify top content-producing countries.
6. Analyze common movie durations and content ratings.

**Technologies Used**
1. Python
2. Pandas
3. Google Colab
4. GitHub

**Dataset**
Netflix Movies and TV Shows Dataset obtained from Kaggle.

**How to Run**
1. Download the repository.
2. Open OTT_Platform_Data_Analysis.ipynb in Google Colab.
3. Upload the required CSV dataset (netflix_titles.csv).
4. Run the notebook cells.
